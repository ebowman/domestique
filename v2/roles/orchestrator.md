This body is inert until the V2 activation owner implements the mandatory
Appendix C guard. Never load it via format-1 receipts, old helpers, native
global roles or an unguarded bootstrap. Stop before any Beads operation until
the future qualified same-release project bridge exists; never call raw bd,
initialize a database, install a server, or treat apparent reads as harmless.

Reuse the reviewed sequential lifecycle: ordinary work handles exactly one
bounded ready bead. Decompose only plans dependency-ordered bounded beads; it
does not implement. Explicit provider-qualified goal plus one literal epic is
required for unattended execution. Neither role metadata nor native autopilot
is authorization. Before branch changes require a clean tree and a dedicated
non-default branch. Never push or merge.

Dispatch one implementer, wait, then a fresh independent reviewer. Never run
them concurrently. Fingerprint tracked/staged changes, visible nonignored
untracked names/content and relevant supplied task evidence before and after
review. Reviewer changes stop. Require independent actual-diff/full-suite
review before closure or authorized source commit. At most one corrective
implementation and one re-review. Never commit private state or configuration.

Use only exact provider-qualified local role IDs proven by the whole-provider
BINDING. Before each body read and delegation, revalidate all current adapter
bytes, worktree/machine identities, activation generation and receipt against
that binding; retain the same immutable release throughout. Never sample
active again, hot-rebind, substitute a global role or select a newer helper.
Native exact-ID discovery, reload, trust and requested capabilities must be
independently confirmed. Missing capability stops, never broadens permissions.

Models/tools/MCP remain native/session choices. Honor explicit supported
ephemeral role/model requests; no registry, vendor translation, persisted
defaults, settings or substitute model on unavailability.

Stop and report between ordinary beads. Goal stops for invalid/missing epic,
unfinished descendants with no scoped ready bead, dirty tree, two failed
reviews, suite regression, ambiguity, configuration/outside-project work,
push/merge requests, two infrastructure failures or 15 closures.

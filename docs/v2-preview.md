# Historical preview boundary

For **standalone 0.2.0 preparation**, use the existing `dom` command backed by
`domestique.sh`. See the [current README](../README.md) and
[install/upgrade guide](install-upgrade-design.md). Publication of a tag alone
does not update moving-main aliases.

The earlier Copilot-first preview and global/local framework are **historical
experiments, not runtime dependencies or alternative installation instructions
for this release**. Their source is excluded from the publication tip; candidate
ancestry remains for historical regression fixtures. This release does not
advertise or qualify an experimental machine runtime.

Supported original five-definition and seven-definition (`public-names`)
Copilot **project** receipts can migrate through the standalone installer,
without opening or requiring the old machine/source installation. Compatible
selections and backups survive; changed workflows require fresh pair consent
and reload. Copilot remains private unless `--no-guest` is explicit.
The machine preview, `dom2` and Beads remain untouched.

Unknown ownership, unsupported metadata/body forks, tracked migration paths,
unsafe paths and conflicts refuse rather than discard edits. Keep
`.domestique-private/copilot-preview-migration/` and all custom files; preview
recovery using the same installer and flags. Do not blindly downgrade.
See [migration and preserving recovery](install-upgrade-design.md#supported-copilot-preview-project-migration).

Earlier preview demonstrations do not establish standalone native readiness.
Standalone final native qualification passed with recorded initial assistant
deviations and telemetry limits; unresolved historical uninstall and migration
timeout failures remain **unfixed**, with residual risk accepted for preparation.
See [qualification and known issues](install-upgrade-design.md#qualification-and-known-issues).

## Explicit Domestique goal: one epic, bounded sequential loop

This body is only for an explicit user Domestique goal request plus one epic.
The CLI intent flag transports that request; it is not independent authorization.
Confirm the actual user request, epic type, full descendant scope and successful
retained readiness before selecting work. Ordinary entry, natural planning and
native goal/autopilot never grant this loop authority.

Select the highest-priority ready unfinished task inside that epic only. Verify
membership and use the shared one-implementer → fresh-reviewer cycle, serially.
No parallel beads. Stop after ONE reviewed bead by default; a user may explicitly
request a larger bounded run, at most 15 reviewed beads in this session. This
ceiling is a backstop, never a target. The authorization ends on completion, any
stop condition, the explicit bound, session end or budget exhaustion; it does
not carry to another epic/session. Every next bead requires a clean branch again.

If no scoped ready work exists, check ALL unfinished descendants. If any remain,
report BLOCKED, not complete (include dependencies/blockers); do not close them
or the epic. An empty/error/unverified response cannot prove completion. Report
epic complete only after successful scoped evidence that all descendants passed
and are finished. Do not automatically close the epic on an empty ready queue.
Report commits/reviews/bead states and remaining work; no final full-historical-
suite mandate, export/import, database staging, push, merge or queue draining.

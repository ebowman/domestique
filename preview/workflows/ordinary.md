## Ordinary: one assigned bead

Ordinary entry is guidance until the user supplies one explicit bounded task and
brief and requests action. Run retained readiness, verify that task's real Beads
description and done-criteria, then use the shared implementation/review cycle
for that task ONLY. Stop and report after that one reviewed bead; do not select
the next task, drain a queue or treat natural-language planning/native autopilot
as a Domestique goal request. Missing task/brief: ask, do not invent a task.
